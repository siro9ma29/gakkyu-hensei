# 学級編制アプリ

新1年生の学級編制を行う、オフラインで動く1ファイルのHTMLアプリです（`index.html`）。
Microsoft Edge / Google Chrome でファイルを開くだけで使えます。

## できること
- Excel（学級編制シート「①引継ぎ入力」形式）からの取り込み、アプリ上での直接入力
- 聞き取りシートに準拠した配慮レベル・保護者対応レベルの自動判定（確定値で上書き可）
- 2〜6学級の自動編制（「離す」は絶対条件、「仲の良い子」はできれば同じ学級）
- ドラッグでの手動調整、児童の固定と再編制、バランス表の即時更新
- クラス名簿／下校グループ名簿／個人カルテ／単票／編制結果サマリの印刷
- データはJSONファイルで保存・読込（ブラウザ内には保存しない）

## 入力用Excel
`template/引継ぎシート_原版.xlsx` は、聞き取り内容を入力するための空のExcelです（児童データなし）。入力後、アプリの「Excelから取込」で読み込めます。

## 注意
児童の個人情報を含むデータ（JSON・Excel・印刷PDF）は、このリポジトリに入れないでください。`.gitignore` で除外しています。
