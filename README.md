# 学級編制アプリ

![version](https://img.shields.io/badge/version-1.6-e8b923)

新1年生の学級編制を行う、オフラインで動く1ファイルのHTMLアプリです（`index.html`）。
Microsoft Edge / Google Chrome でファイルを開くだけで使えます。

## できること
- 園ごとの聞き取りシート（Word）の出力と読み込み（その園の名簿・児童名と◎○のプルダウン入り、読み込む前に確認画面）
- Excel（学級編制シート「①引継ぎ入力」形式）からの取り込み（入れ替え／IDで照らし合わせ）、アプリ上での直接入力
- 聞き取りシートに準拠した配慮レベル・保護者対応レベルの自動判定（確定値で上書き可）
- 2〜6学級の自動編制（「離す」は絶対条件、「仲の良い子」はできれば同じ学級）
- ドラッグでの手動調整、児童の固定と再編制、バランス表の即時更新
- クラス名簿／下校グループ名簿／個人カルテ／単票／編制結果サマリの印刷
- データはJSONファイルで保存・読込（ブラウザ内には保存しない）

## 入力用Excel
`template/引継ぎシート_原版.xlsx` は、聞き取り内容を入力するための空のExcelです（児童データなし）。入力後、アプリの「Excelから取込」で読み込めます。

## 聞き取りシート（Word）
右上の「聞き取りシート（Word）」で園を選んで出力します（1園につき1枚）。各項目は1行に1人（項目｜児童名｜◎○｜具体的な様子）で、児童名と◎○はプルダウンで選びます（名簿にない名前は直接入力できます）。記入したシートを同じ画面から読み込むと、確認画面のあとで児童データに入ります。
- 名前が出た児童：シートの◎○と内容で書き換えます（シートで空欄のところはアプリの内容を残します）
- 記入があった◎○の項目で名前が出なかったその園の児童：未記入なら「なし」にします（◎○が入っていれば残し、確認画面で知らせます）
- 記入がない項目（聞き忘れ）は、だれのデータも変えません
- アプリは左の列の項目名（太字）で項目を見分けます。項目名は変えないでください

`template/聞き取りシート_原版.docx` は名簿なしの空のシートです（アプリの「名簿なしの空のシート」と同じ）。シートはアプリのコード（`hsDocumentXml`）で作っているので、様式を直すときはコードを直してください。

## 注意
児童の個人情報を含むデータ（JSON・Excel・印刷PDF）は、このリポジトリに入れないでください。`.gitignore` で除外しています。
